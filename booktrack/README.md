# BookTrack

BookTrack is a simple React + Tailwind CSS web app for browsing popular books, searching the catalog, and saving favorites locally in the browser.

## Features

- Home page with a mock popular books catalog
- Book detail page
- Search across title, author, genre, and description
- Favorites saved with `localStorage`
- Responsive layout for mobile and desktop
- Optional dark mode

## Stack

- React
- React Router
- Vite
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
